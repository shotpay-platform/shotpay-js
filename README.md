# shotpay-js

JavaScript/TypeScript packages for integrating with [ShotPay](https://app.shotpay.com/docs/).

- [`js-sdk`](./js-sdk) — `@shotpay/node`: server-side client for checkout sessions, layaway contracts, and webhook verification.
- [`button-sdk`](./button-sdk) — `@shotpay/button`: browser-side ShotPay button (vanilla JS + React).

Each package is independently versioned and published; see its own README for installation and usage.
